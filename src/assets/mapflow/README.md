# MapFlow decorative artwork

`welcome-paper.webp` is an original AI-generated watercolor landscape created for the user-approved warm-paper theme on 2026-10-15. It contains no interface text, controls, user information or product data. The generated PNG was encoded as a 1916 × 821 WebP with its alpha channel preserved (370,948 bytes).

The folded-route brand symbol and graphite orbital artwork are native SVG in `src/ui/BrandMark.tsx` and `src/ui/WelcomeArtwork.tsx`. All artwork is decorative; labels, questions and actions remain native HTML. Theme switching and responsive placement belong to the UI styles.
