# 公开阅读页与搜索入口本地验收

2026-10-25。用户确认公开内容页与 SEO 基础方案后实施；本记录只证明本地功能，尚未合入 main、推送或部署，也未绑定站长平台。生产状态仍见 [当前发布](../current-release.md)。

## 本轮行为

- 首页、`/explore`、`/roadmaps/{treeId}`、`/guides` 和教程各章节返回可直接阅读的 HTML，带当前页标题、简介、正式地址和普通链接。关闭 JavaScript 仍可阅读地图正文和使用目录。
- 原 `/library` 互动地图允许游客浏览；收藏进入登录并保留地图、节点等查询参数。登录后不自动收藏，明确再次点击后才生成个人副本。
- 教程弹窗和公开页面共用 `src/content/publicContent.json`。原弹窗目录、下一节和复制命令继续工作；公开章节提供目录和下一节链接。
- robots.txt 返回文本，sitemap.xml 返回 XML；站点清单遍历所有公开目录分页，不编造更新时间。未公开、撤下和不存在的地图不获得公开正文。
- 未知地址、缺失资源返回 404；已知工作台和旧深链接继续工作并标记 noindex。英语世界保持关闭。

公开读取沿用后端公开树库服务的权限规则；没有公开个人笔记、聊天或进度，也未调整模型、费用、执行恢复或写入权限。现有 Caddy 配置直接转发应用，不需要新增运行服务。

2. 前端完整测试 774 通过、1 项原有跳过；TypeScript 和最终构建通过。只保留本轮一个干净的打包目录，含 400 个静态文件；三个生成文件与源码一致。现有依赖、模型和旧会话目录未迁移。
3. 后端公开与静态 HTTP 9 项全部通过，其中 7 项为本轮新增；包含 GET/HEAD、正文、可信域名、防 HTML 注入、分页、私人/归档隔离、资源缺失和 noindex。cargo fmt --check 和完整 Clippy 检查通过，保留原有警告，本轮新增/改动文件没有新增警告。
4. 后端完整未过滤运行共 150 组：1216 通过、1 失败、11 项原有 ignored。知识库使用真实本地 ONNX 服务；没有跳过相关测试或用伪向量替代。

6. Browser Harness 在隔离 Chrome 中检查 320、390、768、1440px，米色/暗色及首页、目录、教程、地图共 32 组，无横向溢出。另验证了关闭 JavaScript、主题按钮、主题保留、手机目录、下一节，以及游客互动地图和登录回跳。修复了实测地图绘图区高度为 0 的游客布局，手机复测高度为 674px。
