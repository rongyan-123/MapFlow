# 手机聊天界面重构验收

日期：2026-10-13。设计已由用户确认：[手机设计](../specs/2026-10-13-mobile-chat-ui-design.md)。前端基础版本 dcd5b7f，开发分支 codex/mobile-chat-ui-20261013。此记录区分已发布的全局助手与尚在手机分支中的界面改动。

## 实际变化

- 全局助手、学习聊天、独立酒馆共用一条 52px 手机操作栏：菜单、对话名、新建、配置、画布。按钮 44×44px，长标题省略。
- 学习区、角色、会话搜索与历史、模型和资金选择进入同一个不透明左侧抽屉。选择、保存和请求继续走原有组件与真实接口。桌面保留原侧栏和工作区。
- 输入初始一行，自动增长至四行并内部滚动；发送与停止使用同一位置的图标按钮。原有失败、审批、恢复和结算状态保留，费用摘要可以展开查看真实用量和余额。
- 手机聊天、地图、画布一次展示一个；对话保持挂载。抽屉和配置在画布上方，关闭弹层恢复滚动与焦点。可视窗口变化只更新容器样式。
- 修复已复现的权限缺陷：首次展开空画布不再写入允许 AI 绘图。用户主动勾选后才保存该权限；手绘保存继续可用。

没有改动后端模型运行、余额结算、充值或日志链路，没有添加自动生成请求。

## 真实浏览器来源

浏览器运行构建后的实际前端，使用 HTTPS 回环预览 `https://127.0.0.1:18102`，API 转发至既有隔离候选服务及数据库 `mapflow_agent_candidate_20261012`。登录使用该候选库的真实管理员和普通测试账号；对话、角色、地图、画布均通过实际服务接口读取或保存。没有网络响应替换、模拟组件或静态数据。

没有对生产账号、充值记录或余额执行验收写入，也没有发起新的收费模型请求。布局显示的旧回复和费用来自已保存的真实生成记录。用户要求只保留 8B 积分模型，其复杂建图能力限制仍存在，本次 UI 工作没有声称解决模型质量问题。
