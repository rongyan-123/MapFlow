## 这次重构的完整产出

1. **四界面和统一左侧导航。** 公共书库、我的地图、学习聊天、独立酒馆保留各自职责；业务入口在左上，模型、额度、帮助、公告、反馈、外观和账号入口在左下。手机抽屉不透明，层级覆盖地图操作，普通账号没有管理入口。
2. **完整学习区与管理助手。** 从本人已有地图建立学习区；每区保存多个独立会话。可以搜索、切换、返回管理层，失效地图的可访问历史不会被静默改绑。没有地图时，管理助手能准备需求草案；用户确认后进入原有地图生成表单，导航和建区不会自动发消息或扣款。
3. **角色与对话的明确关系。** 共享角色库、默认教学助手、按角色筛选历史、新建会话和显式角色切换；角色筛选默认全部。顶部与角色库导入复用同一流程，保留当前会话与输入草稿，新增角色提示在打开列表后清除。
4. **以聊天为中心的学习界面。** 地图按需在右侧打开，绘图讲解和地图切换不同时挂载重型渲染；支持拖动宽度。地图节点可加入指定学习区的聊天参考，不自动发送；返回地图保留节点与视口。
5. **Agent 的资料、工具和权限。** 复用颗粒化地图、节点、笔记、进度工具和教学画布，资料按需读取。管理、学习和独立酒馆由服务端隔离，导入角色卡不会增加权限，独立酒馆不能读取私人学习资料。补齐公开产品帮助与 MCP / Skill 操作说明。
6. **模型设置与错误出口。** 全局和聊天共用非敏感模型偏好，按账号记忆；自填 Key 仅在内存，退出清除。普通界面的错误使用明确类别和通用兜底，私有诊断仍保留。既有流式聊天、现金结算、收款和账单功能继续使用。
7. **笔记草稿、冲突处理和地图恢复。** 未发送笔记按账号、地图、节点保留；关闭和失败可恢复，首次保存或删除冲突允许比较，旧回执不会清除新草稿。已确认地图修改提供恢复入口，校验本人范围、修改后状态及单调版本；恢复结构、笔记和进度不回退聊天、角色、钱包或公共原图。
