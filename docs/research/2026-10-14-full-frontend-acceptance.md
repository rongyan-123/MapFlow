## 实施取舍

| 取舍 | 理由与代价 |
| --- | --- |
| 已获整站授权后连续实施，复用现有隔离分支 | 避免反复确认和新增 worktree；任何调整先留在候选分支，不直接改生产 |
| Windows 使用 PowerShell 工作记录 | 本机没有可用 Git Bash；验证、提交范围与原始日志仍保留 |
| 领域协议和恢复算法迁移，视图重写 | 保持账本、版本、执行身份；算法缺陷仍需独立修复，不因换外观自动消失 |
| 领域客户端保留专用解析，共用 HTTP 边界不自动重试 | 保留注册、支付和执行特殊错误契约；领域解析仍分别维护 |
| 第三方编辑器引擎保留，外围界面重做 | 保持真实编辑和保存能力；Excalidraw 的延迟加载资源仍较大 |
| 长节点内容可在详情完整读取；起点先可读，总览由地图操作打开 | 不把大图首次缩成不可读的小点；首次不同时显示所有节点，用户仍可缩放拖动 |
| 新前端删除旧生成器调用，后端退役留待消费者审计 | 不影响外部消费者和历史记录；服务器旧生成器端点暂保留 |
| 保留私有资料、全部 Codex 会话和已有目录路径 | 不把清理源码扩大为工作区或凭证清理；本机验收服务仍占用少量空间 |

## 独立审查与最终复验

一次独立审查覆盖基线至 `6257dceddd562f6a5c3fd4625f3c715e24b0954f` 的整分支，结论为修复后可合入，没有新增 Critical 问题。执行者完成一次修复过程，处理五项 Important 和两项 Minor：

| 发现 | 修复与证据 |
| --- | --- |
| 延迟发送响应清掉后来输入的草稿 | 按草稿版本清除本次提交；延迟受理和响应丢失均 RED→GREEN，保留原请求身份且仅发一次 |
| 只读历史或未知执行时角色库无法关闭 | 写操作禁用与正在切换角色分开；只读/等待执行时关闭可达，导入、创建、编辑与删除均受保护 |
| 旧 console 只恢复视图，丢失地图与节点 | 读取当前账号的完整选择；个人地图先通过服务器所属列表，URL 选择优先；节点、布局真实联调恢复通过 |
| 已记住学习区被挂载 effect 清空 | 首次恢复与主动返回列表分开；成员验证后写入规范 URL，使手机聊天外壳也正确生效 |
| 地图/画布宽度按钮只改状态 | 修复 CSS 覆盖，接入宽窄预设；键盘实测 657→677px，拖动 677→777px，预设 777→657→877px |
| 外壳与设置主题不同步 | 共用主题变更订阅与跨窗口 storage 订阅；两个方向切换均通过浏览器验证 |
| 退出登录缺少确认 | 共用弹层先确认，取消不退出；确认仅发一次退出请求 |

针对上述回归的首轮运行中有 9 项失败，修复后 31 项定向测试通过；后续还补了学习区恢复后手机外壳的 RED→GREEN 测试。最终完整测试、类型检查、构建和整个分支的空白检查均通过。JS DOM 的入口集成测试只补充浏览器 `ResizeObserver` 环境，不替换地图或领域实现。

最终浏览器新增 15 项检查均通过，未捕获前端运行异常；包含主题、退出取消、键盘和鼠标真实尺寸、画布预设、旧选择、学习区恢复、52px 手机顶部栏、320/390/1024/1440px 展开地图和截图页筛选。另修正桌面学习区下拉框的原生样式及长标题悬停文本。最后 5 项烟测还确认了 1024/1180px 单面板模式隐藏宽度预设、桌面可用预设、长名称下拉不溢出，以及 25 张截图均可读取。截图以构建后的实际页面重新核对。
