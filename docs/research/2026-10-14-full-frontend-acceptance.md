## 实施取舍

| 取舍 | 理由与代价 |
| --- | --- |
| 已获整站授权后连续实施，复用现有隔离分支 | 避免反复确认和新增 worktree；任何调整先留在候选分支，不直接改生产 |
| Windows 使用 PowerShell 工作记录 | 本机没有可用 Git Bash；验证、提交范围与原始日志仍保留 |
| 领域协议和恢复算法迁移，视图重写 | 保持账本、版本、执行身份；算法缺陷仍需独立修复，不因换外观自动消失 |
| 领域客户端保留专用解析，共用 HTTP 边界不自动重试 | 保留注册、支付和执行特殊错误契约；领域解析仍分别维护 |
| 第三方编辑器引擎保留，外围界面重做 | 保持真实编辑和保存能力；Excalidraw 的延迟加载资源仍较大 |
| 长节点内容可在详情完整读取；起点先可读，总览由地图操作打开 | 不把大图首次缩成不可读的小点；首次不同时显示所有节点，用户仍可缩放拖动 |
| 新前端删除旧生成器调用，后端退役留待消费者审计 | 不影响外部消费者和历史记录；服务器旧生成器端点暂保留 |
| 保留私有资料、全部 Codex 会话和已有目录路径 | 不把清理源码扩大为工作区或凭证清理；本机验收服务仍占用少量空间 |

独立整分支审查及其处理结果在候选完成前补录。
