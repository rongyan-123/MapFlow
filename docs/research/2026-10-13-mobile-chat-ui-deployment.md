## 发布与接口验收

使用生产数据库的一致性副本启动发布镜像。隔离网络禁止外网访问，避免验收触发模型扣费；通过候选容器内部真实 HTTP 请求完成检查。Docker 内部网络不转发该候选的宿主机发布端口，初次宿主机 readiness 检查因此不可达，服务实际正常；随后保留隔离条件，从容器回环完成验收，没有替换网络响应或模拟数据。

切换后实际公网 TLS 请求校验首页版本字节，以下路径全部 200：`/assistant`、`/library`、`/maps`、`/learning`、`/tavern`、`/health/ready`。公共技能树接口 200，模型目录返回 51 个不重复模型。钱包、管理员模型与结算接口、私有会话及学习区在匿名访问时均为 401；伪造 Vmq 回调为 400。

没有导入测试账号、会话或余额，没有发起新的收费模型生成。后端代码、模型配置与结算流程沿用此前已发布版本。
