# 手机酒馆顶栏本地验收

日期：2026-10-21。用户确认[右侧方案 A](../specs/2026-10-20-mobile-tavern-header-design.md)后，在 `codex/mobile-canvas-access-20261020` 完成实现。状态为本地预览待检查；未合入固定 main、未部署或操作生产数据库。

## 实际修改

- 小于 768px 的酒馆顶栏只显示功能菜单、智能体与会话、消息、更多。高度 68px，左右留白 12px，入口间距 8px，点击区域至少 44×44 CSS px。
- 智能体入口使用淡色图标底、场景小字与加重名称，去掉整块边框和阴影；长名称省略，完整名称保留在按钮标题和抽屉选项中。点击仍打开原会话抽屉。
- 酒馆“更多”面板以两列卡片显示新建会话、会话历史、教学画布、聊天配置。画布卡片显示当前展开状态；配置卡片直接调用既有配置入口。保留原有额外操作的渲染位置。
- 更多按钮提供展开状态；面板内完成操作后关闭，Esc、关闭按钮与遮罩返回原按钮。配置、画布开关和查看历史不清空当前输入草稿，不发起模型请求。
- 手机学习区保留配置和画布快捷按钮；768px 及以上的原顶栏按钮、60px 高度保留。当前智能体绑定、角色库、独立会话与计费规则沿用原实现。
