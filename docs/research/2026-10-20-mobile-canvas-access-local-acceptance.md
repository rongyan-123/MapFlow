# 手机画布与接入教程本地验收

日期：2026-10-20。状态：已在 `codex/mobile-canvas-access-20261020` 完成本地修复与验收，等待用户检查预览；没有部署或修改线上运行配置。固定 main 仍保持当前已整合远端版本。

## 实际修改

- 小于 1024px 的学习聊天默认收起画布；桌面默认展开、默认绘图授权和酒馆默认收起的规则保留。
- 手机打开画布后占满聊天内容区。聊天 DOM、草稿和执行订阅保留，但隐藏并移出可交互范围。顶栏画笔按钮始终可用，加载中也能收起。
- 开关在点击时立即更新；异步读取只更新原会话的文档，不再在结束时设置打开状态。乱序读取不会覆盖后续编辑的草稿。
- 删除旧的键盘聚焦后压缩为 61px、隐藏绘图编辑器的规则；继续使用已有 visualViewport 高度适配。
- 画布内直接显示保存失败与重试。重新打开不清除未成功写入的保存错误；保存中、未保存、失败和已保存按实际状态展示。只读历史允许重新读取，禁止保存。
- 失败的绘图授权设置也保留在保存队列，重试会重新写入该设置，不再丢失；保存中继续改图和重复重试保持串行。
- 工作台桌面侧栏与手机抽屉增加“Skill / MCP 接入”，直接复用已有安装与授权教程。
- 根据预览反馈，教程在小于 1024px 时改用左上角“目录”按钮打开左侧抽屉，删除顶部横向目录。选择章节后自动收起，正文回到顶部；遮罩、关闭和 Esc 保留原章节并返回按钮焦点。桌面继续常驻左侧目录。补齐共享 Dialog 的最上层键盘处理，避免 Esc 同时关闭目录和教程。
- `VITE_ENGLISH_WORLD_ENABLED` 只有显式为 `true` 时才开放该界面；默认无入口，深链接显示暂未开放，不请求英语世界数据。原后端开关未改。
