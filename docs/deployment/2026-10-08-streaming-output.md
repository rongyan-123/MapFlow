1. 画布支持 `mouse+` 上滚、`mouse-` 下滚的主、副快捷键及账号记忆。仅画布内执行；输入框、聊天及缩放手势保持原行为；未绑定时保持原生滚轮行为。

3. 输出默认为“模型默认”，请求省略未指定的 `max_tokens`；撤销本站统一 8192 上限及 u16 容量限制，显式参数使用正整数 u32。用户明确保存的旧长度保留；0038 只迁移未修改的版本 1 默认 2048，历史回执不改。
4. 带工具的 DSH 分支传递输出、温度、停止词，并清除会话复用后的旧覆盖；日志读取工具白名单与 worker 一致。过程流落后时记录原因、恢复快照并跳过重复帧。
5. 保存有效请求参数、真正的原始结束帧及原始用量。空字符串和 null 结束标记不逐增量写库。length 保留部分输出并按失败处理，不扣本站现金，不自动发起额外收费请求。直接模型等待由 120 秒改为 900 秒。

仍保留单条输入 8 KiB、按字节裁剪的 8/16/32 KiB 历史、工具次数与权限、协议容量和适配器能力。平台额度和自填 Key 使用本站 Rust 模型循环，不能称作完全裸 DSH。旧独立报价接口的 8192 估算预算不用于当前现金发送预留或拦截。
