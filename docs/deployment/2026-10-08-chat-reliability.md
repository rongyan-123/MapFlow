# 教学聊天失败与恢复

截图中的 HTTP 流式请求已经建立，但模型回合失败，历史记录没有提交生成或本站现金扣款。旧诊断将多个上游原因合并成通用错误，因此无法从截图证明一定是 URL 配错。

## 改动

- 明确失败显示“本次生成失败，未扣除本站额度”，保留输入和原重试标识。
- 推理耗尽输出上限时提供“调整生成参数”，打开现有模型参数窗口。
- 服务故障和不完整回复可打开模型配置。错误文案不展示上游、供应商、URL 或供应商余额；保留简短提示和请求编号。
- 可确认的服务器 DNS/网络不可达单独显示“服务器网络异常”，与浏览器连接失败、普通连接拒绝及输出上限区分。
- 连接中断、代理 502 或丢失完成帧时，先 GET 同一会话。若服务端已提交相同请求，恢复最终回复与费用；不会自动再次 POST。
- 刷新后的待确认请求也会查询已保存记录；查询失败保留原始错误和请求标识，不误报已扣款或未扣款。

后端同时修复多工具批量调用、八次工具后的最终回答和 `[DONE]` 的 EOF 兼容，增加输出上限、服务故障和不完整回复分类及安全的管理员诊断。真实账单的累积结算、失败不扣本站现金、幂等重试和审批限制保持有效。
