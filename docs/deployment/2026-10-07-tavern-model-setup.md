## 用户交互

缺少模型配置、Key 无效或上游连接失败时，消息旁显示“填写 API Key 或使用平台额度”，点击直接打开配置的模型页。余额不足时提供充值入口；打开配置保留尚未发送的文字。

自填 Key 增加爱你 AI、DeepSeek、OpenAI、通义千问和自定义预设。用户修改草稿后点击“保存并使用”才应用；测试连接只读取模型列表，不生成聊天、不扣本站余额。获取列表后可以选择模型，也允许手动填写。切换预设清除草稿 Key 与旧测试结果；同一酒馆页面内切回自填 Key 可恢复已经保存的配置。Key 只保留在页面内存，刷新后需重新填写。

平台模型选择器显示上下文和本站输入、输出人民币价格，单位为每百万 Token。多个启用渠道显示价格范围；未获取到价格时明确提示。直接使用后端已计算的本站价格，不重复换算。此次没有修改实际结算规则，也没有恢复发送前的费用确认弹窗。

新增 `POST /api/me/tavern/model-access/test`：要求登录和 CSRF 验证，拒绝私网 URL，复用公共 HTTPS 地址校验及 DNS 固定结果；不跟随重定向。测试限制并发、请求时间、响应大小及模型列表数量，错误消息不转发上游原文或 Key。
