## 当前行为

平台现金余额严格大于 0 时允许发送，不再请求报价或预留费用。成功后按完整上游实际账单 × 2 结算，并与消息、用量和流水一起提交；允许本次结算产生负余额。余额为 0 或负数时拒绝下一次平台生成，提供充值入口。失败、缺失完整费用、持久化回滚不扣本站现金。自填 Key 不扣本站钱包。

同账号的现金生成跨会话串行取得发送资格，后一条在前一条结算后重新检查余额；不同账号仍可并发。请求重试先恢复已保存结果，即使已经欠款也能恢复，不重复扣费。平台多轮工具调用合并实际费用后结算。旧报价协议仅用于兼容旧客户端，不创建预留，也不按旧预留上限截断实际账单。

充值可以抵扣欠款，即使充值后仍为负也正常入账；Vmq 重复回调只记一次。管理员在“管理面板 → 充值 → 充值设置”保存 Q 群号，留空关闭。已确认入账的充值页面显示入群提示，待付款或待核实不显示。设置保存在数据库中。

价格页和平台模型配置分别标注输入缓存未命中、输入缓存命中、输出及每百万 Token 单位。当前 AnyAI 渠道接口没有提供缓存命中价，因此明确写“未提供”，不使用未命中价格或自行推算的折扣冒充缓存价。渠道摘要显示可用渠道的价格范围，实际结算使用完整账单。

选择个人树先显示地图。进入节点学习聊天时，酒馆占满内容区域，卸载地图并去掉聊天宽度拖动分隔条；可点击“查看地图”和“返回聊天”切换，保留选中节点、角色和同一会话。独立酒馆与学习酒馆继续互通角色、消息、上下文和工具授权。

管理员面板进入即检测上游余额，每 90 秒刷新。服务端访问固定 `/v1/skills/balance`，短缓存 60 秒，美元单位原样标注；耗尽显示提醒，网络或数据异常单独显示检测失败。读取余额及修改 Q 群均要求服务端管理员权限，写操作另验 CSRF，不向浏览器返回服务器 Key。
