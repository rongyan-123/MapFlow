## 用户行为

个人技能树右侧使用酒馆工作区。顶栏的“独立酒馆”保留独立布局。两个入口使用同一个角色库、会话 ID 和持久化消息；已有学习聊天正文按个人库条目接入一次，不产生重复收费。没有关联会话时创建以技能树命名的学习助手。

已有或导入的角色可以在会话的“配置 → 技能树与工具”选择自己的个人技能树，勾选“允许使用技能树工具”，点击“保存工具设置”。权限保存在会话上。关联树但关闭工具时仍可使用树上下文；开启后可读取树、搜索资料并提出修改，每次修改需用户确认。取消勾选并保存即撤销工具权限；两个入口同步使用这一设置。

切换角色保留聊天历史和树授权。配置、角色切换与生成互斥，并校验会话版本。审批只接受对应账号、会话和树，执行前重新检查生成与授权状态。不能将已过期生成的审批用于修改树。

平台和自填 Key 使用受控工具循环。平台总实扣合并各次模型请求后结算；失败释放本站预留。工具循环最多四次模型请求，预留按工具预算估计，实际费用与余额继续显示。未改变现金结算倍率，也未恢复发送确认窗。
