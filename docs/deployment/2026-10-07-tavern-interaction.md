## 用户可见变化

1. 接入方式记住上次的平台额度 / 自填 Key 选择，并保存各自模型、公开 API 地址及历史容量。同一浏览器按账号隔离，独立酒馆和学习酒馆共享；恢复平台模型时读取当前目录，已下架模型给出重新选择的引导。API Key 仅在当前页面内存中，刷新后需要重新填写。
2. 聊天顶部增加“新建会话”，继承当前角色、树关联和当前工具权限，旧聊天与画布保留。创建期间阻止重复点击；关联失败后重试复用已创建会话。技能树记住最后选择的会话，历史缓存不会覆盖该选择；独立酒馆读取相同服务端记录。
3. “绘图讲解 / 展开画布 / 收起画布”移到顶部工具栏。收展与宽窄切换采用约 250ms 的缓动和淡入淡出，支持减少动态效果；编辑器保留挂载，图形、视口和撤销不因收起而清空。手机画布模式保留聊天、配置与参数入口，工具栏可换行。
4. 输入框“参数”直接打开独立“模型参数”弹窗，包含温度滑块、当前值、模型默认选项、最大输出和高级停止词。原总配置移除生成参数分类；保存、再次发送和版本冲突处理沿用现有服务端接口。

生产构建检查还发现字体预加载早于组件内字体路径设置。现将路径设置提前到页面启动阶段，使懒加载画布使用本站字体。公网实际字体响应均来自 xxian.fun 且返回 200；库注册的外部备用地址被既有 CSP 拦截，没有外部字体下载。
