# 酒馆 P1 主线合流与验收

目标：在独立集成工作树中保留现有酒馆 P1 工作成果，同时吸收当前 MapFlow 主线（包括知识聊天 SSE 热修、节点笔记与公开功能），不改动原始工作树或正式站点。

规格依据：`docs/specs/2026-09-24-tavern-native-capability-roadmap.md` 和 `docs/specs/2026-09-20-tavern-rolecard-mvp-design.md`。

## Task 1：建立可审计的集成基线

- 从两份酒馆工作树机械复制已存在的未提交改动到新集成分支；原目录不动。
- 记录原分支与主线的差异、迁移冲突和知识聊天热修缺口。
- 验证：复制前后的文件清单与哈希一致；定向酒馆测试、前端和 Worker 类型检查通过。

## Task 2：合并主线并解决接口冲突

- 在新分支合并各自当前主线；酒馆迁移从主线 `0020` 后顺延，保持迁移顺序和账本单写入者约束。
- 只在合流冲突处修改行为；新增/改动逻辑先写外部接口回归测试、看红、再实现。
- 验证：迁移在隔离 PostgreSQL 中执行并对账；Rust、Worker、前端全量测试，类型检查、构建、fmt/clippy、diff 自审。

## Task 3：真实验收与交付边界

- 在隔离环境用真实第三方卡完成 Reply、Regenerate、Continue、Swipe、编辑、分支、检查点、刷新和 300 秒后的续聊；核对积分流水与观测。
- 不在本计划内部署正式站点；真实模型、浏览器或数据库环境不可用时明确记录未验收项，不宣称完成。
- 验证：浏览器点击记录、隔离数据库回合/账本对账、健康检查与无敏感内容日志。

## 本地集成验收结果（2026-09-26）

- 服务端集成提交 `984981d`，前端集成提交 `8b231ac`；原酒馆工作树未修改，正式站点未部署。
- 主线 `0020` 节点笔记迁移保留，酒馆迁移顺延至 `0021`–`0024`。SQLx 迁移发现测试先因版本重复失败，修正后通过；全量迁移在独立 PostgreSQL 中执行成功。
- Rust 全量测试、前端 400 项测试、Worker 81 项测试通过；前端/Worker 类型检查和构建、Rust 格式检查通过。严格 Clippy 仅因五项既存基线 lint 失败；屏蔽这五项后无新增 lint 错误。
- 隔离站点使用真实第三方 PNG 卡及测试 Worker，经 Browser Harness 实际点击完成导入、空/非空词表会话、发消息、重生成、切换回复、检查点、分支、编辑、续写、刷新与参数保存。生成参数 `temperature=0.7` 已持久化。
- 空闲超过 300 秒后再次发送，测试 Worker 收到 `resumeSession=false` 与包含已编辑消息的持久化历史；会话可续聊。隔离库有 5 次生成、5 条酒馆积分流水，积分单位总和均为 15；检查点、分支、编辑和切换回复没有新增流水。
- 该验收使用协议测试 Worker，不评价真实模型的剧情质量或线上服务稳定性；未执行正式部署。
