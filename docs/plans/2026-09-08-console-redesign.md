# 控制台重构：从介绍页到地图库

用户已授权自由设计及实施；本轮只改控制台，已验收的产品页与插图保留。主 agent 负责设计、审计及 Browser Harness 验收，产品代码由 Luna / max 子智能体实现。

## 观察与目标

浏览器基线：1440 × 900、390 × 844，预览端口 5177。公共目录来自实际只读接口。

- 手机首页的大标题、介绍及装饰编号使第二个方向落到首屏以下；两个方向不便比较。
- 方向详情重复大标题、返回入口和绿色装饰面板，适合人群与基础要求反而被折叠。
- 地图界面预留空详情栏，手机缩略图明显遮挡内容；跨尺寸切换需确认视口适配。

目标是让用户知道现在可以做什么：新用户选方向、了解起点；已有地图的用户从真实记录继续；进入地图后以地图与当前节点为中心。

## 设计

1. 首页采用紧凑地图库，简洁标题、次级创建入口、可比较的领域条目。手机直接展示探索与我的学习导航。
2. 个人地图展示真实完成数与总数，允许逐项继续；不把 API 第一条伪装成最近访问，不编造时长或连续学习数据。
3. 详情页说明适合谁、所需基础、推荐节点与起始问题。开始探索与只读预览保持现有动作语义，删掉重复口号及纯装饰块。
4. 地图阶段保留暗色画布；目录更紧凑，未选择节点时不占用完整详情栏。手机控件与缩略图不能遮住主要阅读区域。
5. 加载、失败、空状态分别呈现。身份隔离、待登录探索意图、加入地图、草稿、聊天与进度保存保持原有业务契约。

## 实施与验证

- Luna 实施首页、方向详情与控制台外壳；视觉调整通过桌面、手机截图验证。
- 地图适配问题先复现，新增状态逻辑先测试失败再实现；不对纯样式编写镜像测试。
- 在隔离的浏览器 API 替身中验收返回用户、个人空状态与错误状态；替身禁止实际 API 写入。真实预览仅执行公开读取。
- 检查目录 → 详情 → 预览 → 节点 → 返回，以及登录入口、个人继续入口与权限禁用状态。
- 完成前运行完整测试、类型检查和生产构建，自审 diff；本轮不推送或部署。

## 验收尺度

390 × 844 的公共目录首屏能比较两个方向并找到入口；方向详情无需先读长篇介绍才能看到操作；桌面空节点详情不占整栏；移动端无水平溢出。已有测试覆盖的身份、学习记录、生成和聊天流程继续通过。
