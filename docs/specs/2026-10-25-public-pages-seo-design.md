# 公开阅读与搜索入口

2026-10-25 用户已确认“公开内容页＋SEO 基础”方案，先本地预览和验收。本轮复用 b869 前后端工作区，从各自最新 main 建立 `codex/seo-public-pages-20261025`；不部署、不购买服务、不注册外部账号。

## 为什么做

现有公开地图接口允许匿名读取，但前端全局登录判断挡住了公共书库。首页、教程、地图缺少完整的公开阅读入口；robots.txt、sitemap.xml 和不存在的地址都回退到首页 HTML。目标是让游客先阅读有用内容，再选择注册，并使搜索引擎能够发现和读取这些内容。

## 页面与权限

- `/explore`：服务端输出的公共书库，真实链接和分页，只读既有公开目录。
- `/roadmaps/{treeId}`：固定的公开地图阅读地址，展示标题、简介、节点说明、学习目标及知识关系；提供进入 `/library?tree=...` 互动地图的链接。
- `/library` 及其 tree 查询：现有互动书库允许匿名使用，匿名收藏引导至登录并保留原地图地址；登录后仍需明确执行收藏。私人书库和所有写操作沿用原登录／CSRF／归属验证。
- `/guides` 与 `/guides/{sectionId}`：使用说明及 Skill/MCP 教程的公开页面。现有弹窗继续工作，弹窗和独立页面共用同一份内容。
- `/`：公开首页保留既有交互入口，初始 HTML 提供可读正文和实际链接。
- 只使用既有 public/showcase 读取能力，不把私人地图、笔记、聊天或后台资料转为公开；不增加模型调用。
- 私人、下架和不存在的地图的新读取请求返回 404；不保留公开 HTML 长缓存。站点清单使用同一公开目录，撤下后不再列出。已经下载的浏览器内容无法追溯收回。

## 输出与共用内容

Rust 在现有公开路由中提供 HTML，不新增运行服务或迁移前端框架。公开页给所有访客返回同一正文，不通过爬虫 User-Agent 切换内容。

前端 `src/content/publicContent.json` 为教程和公开文案真源；既有教程导入此内容。构建／开发启动时将同一文件及公开页样式、少量主题脚本输出到静态目录，后端从该发布包读取。前后端作为一个版本验收，缺少内容资源返回明确的不可用状态，不生成伪教程。

公开阅读页不启动整个登录工作台。互动地图仍走现有 React 页面；阅读页提供直接进入互动地图、注册和登录的链接。米色、暗色及手机阅读布局沿用现有视觉方向。

## 搜索基础

- 每个公开地址有自己的标题、简介和规范地址；规范域名取现有可信 public_origin，不从请求 Host 拼接。
- 输出语义 HTML 和普通 a/href 链接，节点目录可定位到正文；所有来自地图、教程和查询的文字做 HTML 转义。
- robots.txt 返回正确文本，sitemap.xml 返回 XML，仅列公开阅读地址，包含分页中全部已发布地图。未知修改时间不编造 lastmod。
- 未知地址、缺失资源和失效地图不返回首页 200。保留已知工作台、旧 console 及英语世界深链接的兼容入口；英语世界仍关闭。
- 登录／工作台页不进入 sitemap，使用适当的 noindex；权限由原服务端验证，robots 不是访问控制。
- 元数据、基础文件、HTTP HEAD、分页和错误状态通过真实 HTTP 行为验证。

## 验证面与顺序

沿用用户已确认的验收：游客可读、搜索引擎能读正文、私人／下架不可读、收藏登录流程正常、原聊天不变。

1. 前端 Application 游客书库、详情、登录回跳及真实链接测试先红后绿，使用公开接口响应和真实界面。
2. 后端公开 HTTP／真实 PostgreSQL 测试先红后绿：正文、正确状态、分页、标题／规范地址、转义、私有与下架隔离、站点清单与规则。
3. 教程共用内容及公开 HTTP 页面按同一入口验收，保留现有目录、下一节和复制命令测试。
4. 完整前端测试、类型／构建；后端相关测试、完整套件、格式和静态检查，明确报告既有 Windows 网络分类差异。
5. 独立本地数据库与示例内容启动预览；真实浏览器检查桌面／手机、米色／暗色、匿名浏览、互动地图、登录回跳和关闭 JavaScript 的阅读页。保留可供用户查看的地址，不切换生产。

## 外部工作

Google Search Console 与 Bing Webmaster Tools 的基础官方工具免费。站点所有权验证需用户站长账号／域名权限，尚未授权登录、绑定或提交。此轮先准备可验证页面和清单；不声称已经接入、已经收录或保证排名，也不把站长平台等同全站访问统计。
