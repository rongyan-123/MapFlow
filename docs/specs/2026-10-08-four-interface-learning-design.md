## 1. 要求优先级与纠正范围

用户本轮明确：附件《MapFlow 四界面与学习区重构交接方案》优先；口述的两个界面构想是旧要求。因此重新确定入口、会话归属、布局、工具范围和历史迁移，不只修改导航数量。

按附件已确认方向准备：

- 四个独立业务界面：**公共书库、我的地图、学习聊天、独立酒馆**。
- “学习区”是一张个人地图对应的持续学习空间，可有多个对话与角色。
- 学习聊天先有完整的学习区选择/管理层；全局管理助手在这一层，不增加第五个主界面。
- 我的地图独立全幅查看；学习聊天按需左聊天、右地图，不要求地图长期渲染。
- 角色卡在当前账号内共享；对话按管理助手、学习区、独立酒馆归属展示与授权，不新造三套聊天数据库。
- 学习区只读和修改所属地图；独立酒馆不关联学习地图、不访问私人学习资料；全局助手针对明确任务查找和管理当前账号地图。
- 保留地图、笔记、进度、角色、消息分支、教学画布、模型配置、支付计费及辅助入口。

附件第 5 节具体权限矩阵和写入策略仍是**待确认建议**。确认四界面及附件优先级，不表示每个写入动作已获批。

原两界面草案标为作废，原提交 `80fb7a6` 保留。此前有效源码事实继续使用；跨图学习、统一全部历史、取消独立酒馆等旧草案安排不再采用。

## 3. 四页面与导航

### 公共书库

保留搜索、筛选、分页、预览及加入个人库。加入后沿用私人副本，不自动调用模型，不把公共原图设为修改目标。可前往我的地图或该副本学习区。

### 我的地图

个人地图列表和搜索；打开后独立全幅查看，保留节点、笔记、进度和管理，不强制聊天分栏。

节点按钮“进入学习区，向 AI 提问”：根据明确个人地图 ID 幂等取得/创建学习区，恢复可用对话或准备新对话，加入待发送节点引用。**不自动发送、收费或重新生成地图**，明确目标优先于最近区。

失败保留地图、视口、节点和草稿；保存中的笔记完成保存或明确处理未保存状态再跳转。返回恢复缩放、位置与选择。

### 学习聊天

未选区时完整展示学习区/地图列表、搜索、手动新建及管理/新建助手，不用弹窗强制选图。全局助手在这一层，不增加业务导航项。

区内顶部“学习区：地图名称 ▾”可切区或返回管理层。按账号记住最近区与对话；一图区可有多段对话，新建继承区地图，默认学习助手直接可用。资料范围只包括所属图，其他对话全文不自动合入。

左侧仅当前区历史，角色筛选默认“全部角色”，不换当前对话或发言角色；顶部单独显式切角色，保留历史与标题并标记切换位置。

默认聊天阅读；需要时右侧展开地图，**左聊天、右地图**，可拖宽和收起。地图懒加载，隐藏时不持续昂贵渲染，拖宽不反复布局整树。教学画布是可展开的对话工具视图，与地图切换显示，避免常驻多个重型渲染器。

无权访问地图时不改绑其他图，保留仍可访问的历史并回选择层说明。浏览其他地图不会自动切学习区。

### 独立酒馆

独立页面，可新建对话、导入/自创/编辑角色。角色库共享，历史仅展示酒馆场景；不要求地图或学习区，不提供个人学习地图、笔记、进度及学习聊天读取权限。

保留现有独立画布和绘图开关、正常知识问答；提示系统学习请前往学习聊天。不能把“没有学习工具”变成禁止讨论知识。

### 辅助入口与移动端

模型/接入、模型价格、钱包/充值、额度消费、外观、账号、教程、MCP/Skill 连接、公告、反馈、首页与退出继续可达。管理员菜单及接口维持管理权限校验。

参数仍由聊天附近按钮独立打开，平台/自用模型偏好按账号记忆。移动端抽屉与单区域切换，不硬塞双栏。本轮不重做首页、支付和定价。

## 4. 角色和历史交互

- 筛选只影响当前场景/学习区列表，默认全部；当前角色独立于筛选，不因查看历史而自动替换。
- 各处导入共用流程，成功显示名称和“使用”；不换会话、不清草稿、不覆盖当前角色。
- 选择器显示“新增 N”或红点，打开角色菜单后清除；按账号隔离，失败不增加计数。
- 编辑、重命名、隐藏继续保留，隐藏不删历史；旧角色快照不会因角色库编辑被暗中替换，应用到会话须显式操作。
- 学习新对话继承所属图，酒馆不继承学习资料；管理对话不混入区内或酒馆历史。
- 刷新以服务端场景、区及会话 ID 为准；本地选择偏好不是权限凭据。

## 5. 权限建议与知识检索

下表仍待实施前确认，不因四入口已确定而自行开放所有写操作。

| 能力 | 全局管理助手 | 学习区助手 | 独立酒馆 |
|---|---|---|---|
| 产品教程 | 按需 | 按需 | 按需 |
| 查找个人地图 | 账号内分页目录/搜索 | 仅所属图 | 不提供 |
| 节点/笔记/进度阅读 | 明确任务和目标后按需 | 仅所属图，颗粒化读取 | 不提供 |
| 建图/建学习区 | 明确请求，沿用真实流程 | 不跨区创建 | 不提供 |
| 修改图/笔记/进度 | 明确目标变更，确认后执行 | 所属图，确认后执行 | 不提供 |
| 其他对话全文 | 不默认开放 | 不合并其他对话 | 不访问学习聊天 |
| 自身画布 | 单独授权 | 单独授权 | 单独授权 |
| 支付/密钥/权限/管理员操作 | 不提供 | 不提供 | 不提供 |

建议只读按授权自动执行；修改展示具体变更并走现有确认，删除/覆盖逐次确认，手动保存不重复问。撤权后未提交操作必须复核拒绝，模型提供的 ID 不代表授权。

管理助手先拿紧凑索引确定任务目标，再逐步读取；学习区继续小概览、搜索节点、读取所需字段/关系，不整树注入、不读所有笔记历史。跨图任务由用户切学习区或回管理层，不临时把其他私人图塞进区内。

产品知识库独立整理教程、功能、模型设置、地图、角色与连接说明，按功能/版本检索。不注入组件源码、密钥、运维资料、原始错误日志或其他账号内容；缺资料时不虚构功能。

服务端每次核验账号、场景、区和目标；确认绑定具体变更及版本。角色/地图文本不是权限凭据。场景、角色、资料或授权变化进入配置指纹，不能用旧缓存扩大范围。

工具失败保留可纠正的结构化结果和持久化诊断；普通 UI 映射安全文案与编号。诊断工具同样检查范围，酒馆不能借日志工具读取学习资料。

## 6. 历史迁移、运行和发布边界

新增场景与学习区归属，复用现有会话、消息分支、角色、画布、计费及诊断表，不复制、合并或删除历史消息。

推荐分类，须副本盘点后确认执行：

1. 已关联地图的旧会话进入对应学习区，无论旧 UI 是酒馆还是地图聊天；保留 ID、角色、分支、画布及费用，说明现在位置。
2. 未关联的旧酒馆会话归为酒馆，不增加学习权限。
3. 新管理对话明确标记管理场景，不把旧所有记录归入管理助手。
4. 导入标记继续去重；重复进入、并发建区、迁移重跑不重复建区/导入。
5. 失效关联保留失效状态与可访问历史，不静默变为酒馆绕过权限。

服务端拒绝酒馆旧关联接口、伪造目标及学习日志读取，不能只隐藏按钮。旧关闭工具的会话不因迁移开启写权限。

请求绑定账号、场景、会话、分支和请求 ID；切区/页面后结果仍归发起对话，运行控制层不随可见面板切换丢失归属。本轮不增加账号并发上限，保留现有并发/幂等规则。

刷新按真实持久化恢复，不承诺未保存文字全保留。保存、收费和已提交修改依据实际记录显示。现金正余额发送、实费结算、负余额与失败规则保持，不加回最高预留拦截。

使用新增迁移，不改历史校验和，包括 `0037`；编号实施时核对主线。旧 `/console`、`/tavern` 和会话深链兼容，钱包/模型返回保留来源。回退使用能读当前数据的版本，不能还原整库抹掉新充值。
