# 手机聊天界面重构设计

日期：2026-10-13。阶段：设计待审阅，尚未修改产品界面。现有全局助手的 main 合并与部署已获授权，单独执行；本文不将手机设计分支作为发布材料。

## 目标与已有问题

用户要求参考豆包式手机交互：打开就是聊天与输入框，顶部操作只占一行，左侧菜单打开后才展示导航和选择。新建对话、配置、展开画布均在同一顶部行。

当前源码中五个层次各自输出标题或操作行：ApplicationShell 的全局导航、LearningChatWorkspace 的学习区选择、AgentTavernPage 的资金与模型选择、TavernPage 的角色/会话操作、ConversationPane 的画布入口。它们在手机上叠加，属于布局职责重复。输入框里的长模型标签还挤压发送按钮。此设计由一个手机页面外壳接管这些入口。

## 推荐布局

全局助手、具体学习聊天、独立酒馆采用同一种手机骨架，沿用 MapFlow 的深色底色、青色强调色与现有角色数据。

```text
┌───────────────────────────────────┐
│ ☰   对话名称…        ＋   ⚙   ▧   │  唯一顶部栏
├───────────────────────────────────┤
│                                   │
│ 用户消息                          │
│ 助手回复                          │
│ 可展开的思考、工具过程及用量       │  唯一主滚动区域
│                                   │
├───────────────────────────────────┤
│ 输入消息…                     ↑   │  紧凑输入框
└───────────────────────────────────┘
```

- 顶部内容高 52px，另计设备顶部安全区；不换行。按钮触控区域至少 44×44px，使用有无障碍名称的图标。标题单行省略，可在抽屉查看完整名称。320px 宽仍保留全部四个按钮，不挤出屏幕。
- `☰` 打开统一左侧抽屉；`＋` 直接新建当前场景的对话；`⚙` 打开配置；`▧` 展开/收起当前对话的教学画布。尚未创建对话或正在运行时使用实际业务条件禁用相应动作。
- 学习地图入口放在抽屉的“当前学习区”中，与画布分别命名。手机每次只展示聊天、地图或画布之一；顶部一行继续可达。
- 角色头像、场景介绍、完整地图名及资金通路不在聊天顶部另外占行。节点引用作为可删除的小标签放在输入框内，只在确有引用时出现。
- 助手消息不使用巨大的头像缩进；正文默认 15–16px，正常换行。代码块和表格在自身区域横向滚动，整个页面不横向溢出。消息编辑/重新生成/继续收进每条消息的操作入口。
- 本次费用与 Token 使用紧凑摘要，可展开查看完整用量和余额。失败重试、写入确认与待核对等业务状态继续可见，不用静态成功外观替代真实状态。

## 左侧抽屉

只有一个手机导航抽屉，采用不透明面板并覆盖画布、地图和它们的操作菜单。关闭时原聊天不卸载，输入草稿、流式订阅与滚动位置保留。

抽屉从上到下：

1. 当前场景与业务入口：全局助手、公共书库、我的地图、学习聊天、独立酒馆。
2. 当前场景的选择区：学习区切换/返回学习区列表（仅学习场景）；角色选择、导入、自创与“新增角色”提示；角色筛选默认全部。
3. 当前场景/当前学习区的对话列表：搜索、选择、重命名、删除等已有能力。新建对话顶部可直接使用，这里也保留列表上下文。
4. 模型与额度：当前资金通路和模型摘要、打开模型接入/模型参数、钱包及价格入口。选择偏好继续按账号记忆，自填密钥沿用原存储规则。
5. 帮助、外观、账号与管理员专属入口。

点击导航、历史或学习区后关闭抽屉；展开抽屉内的选择器不再打开第二个侧栏。导入/编辑角色等较长表单使用适配手机的对话层，完成后回原上下文。筛选历史不暗中切换正在聊天的角色。角色导入仍保持原对话和输入草稿。

## 输入、配置与画布

- 输入框初始一行，随输入自然增长至四行，之后在输入框内部滚动；内容区剩余空间全部给消息。发送使用单个箭头按钮，运行时同位置切成停止按钮，图标均有明确名称。
- 模型、现金/积分/自填 Key 和参数通过顶部配置或抽屉进入，聊天输入区不再塞多个选择器。配置默认恢复上次选择，参数继续独立成页或面板，不改变既有保存与发送语义。
- 手机触控键盘打开时输入框跟随可视窗口底部，避免被键盘和浏览器工具栏遮住。使用动态视口与实际可视窗口验证，不锁死为桌面高度；中文输入法组合期间不误发送。
- 画布在手机上占满消息区域，使用同一顶部栏收起；开启/关闭有约 200ms 过渡。保留缩放、拖动、保存、快捷键设置与 AI 绘图权限。未授权绘图不会因为界面重构而开启权限。
- 抽屉、配置与画布有清楚的关闭和返回行为。打开弹层期间冻结背景滚动、管理焦点；关闭后回到原触发按钮。减少动画偏好下直接切换。
- 公共书库、我的地图、学习区列表和辅助页面复用单行导航及抽屉；列表、表单、充值和管理页面继续使用各自真实业务，必要的页内标题不是聊天操作栏。

## 实现范围与边界

预计涉及以下现有前端模块与相应测试，可能新增共享手机顶部栏和场景抽屉组合组件：

- `src/features/navigation/ApplicationShell.tsx`、`MobileDrawer.tsx`：统一手机外壳和抽屉。
- `src/features/assistant/AgentTavernPage.tsx`：将资金、模型控件接入共享配置入口。
- `src/features/learning/LearningChatWorkspace.tsx`、`LearningMapPanel.tsx`：学习区选择和地图模式接入共享外壳。
- `src/features/tavern/TavernPage.tsx`、`ConversationPane.tsx`、`TeachingCanvasPanel.tsx`、`TavernUi.tsx`、`teachingWorkspace.css`：移交重复操作栏、消息/输入布局、画布工具适配。
- `src/App.tsx` 与手机视口辅助：场景入口挂载及键盘/视口行为，按实际需要修改。

对话和角色仍读写现有数据库，运行、日志、支付、模型结算和权限使用现有后端。桌面保留既有侧栏与可拖动工作区。此次发布不增删业务场景，不新增收费或自动请求，不清空历史及草稿。

## 实施步骤与验证

| 步骤 | 做什么 | 怎么验证 |
| --- | --- | --- |
| 1 | 统一手机顶部栏、场景选择和抽屉入口 | 新增交互测试先红后绿；三个聊天场景只有一个顶部栏，全部现有入口仍可访问 |
| 2 | 收拢角色、学习区、对话历史和模型选择 | 真实已有账号/数据浏览；筛选、新建、切区、切会话、导入、关闭抽屉后草稿/选择不丢，不自动发送 |
| 3 | 重做消息和紧凑输入区，适配可视窗口 | 320/360/390/430px 宽、横屏、长标题、中英文输入、键盘开关、长代码/表格；发送/停止触控区域、无横向溢出 |
| 4 | 画布与地图全屏切换及弹层层级 | 真实画布保存和地图参考；聊天订阅保留、配置可达、抽屉不被下层菜单盖住、工具权限保持 |
| 5 | 完成检查并准备可审阅发布版本 | 完整前端测试、类型检查、构建、自审 diff；真实应用手机浏览器截图对照，桌面回归，必要的真实模型/结算验证记录来源 |

纯样式用浏览器验证；新增交互状态与业务动作先写测试并确认失败，再实现。手机界面确认实施后执行，完成验证后按具体版本发布授权处理。
