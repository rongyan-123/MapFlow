# 酒馆接入偏好、会话与画布交互

2026-10-07：用户已确认下列四项范围。复用现有酒馆、会话关联和生成参数接口，在当前页面实现，不改现金结算规则。

## 用户行为与数据

1. 同一浏览器按账号保存接入线路、已选模型、公开 API 地址及历史容量。独立酒馆和技能树教学共享这份偏好。恢复平台模型时读取当前模型目录和结算协议，失效模型明确提示重新选择。API Key 仍只保存在当前页面内存，不写浏览器持久存储。
2. 增加显眼的“新建会话”。新会话采用当前角色，在技能树中继承当前树关联与工具开关；旧会话、聊天与画布保留。创建期间防止重复提交，失败可重试。按树保存最后选择的会话，重新进入后恢复该树的选择，并验证所选会话属于该账号和该树。独立酒馆能打开同一服务端会话。
3. 教学画布开关从输入框移到聊天区顶部。展开、收起及宽窄切换采用约 250ms 缓动与淡入淡出，尊重减少动态效果设置。动画期间和再次打开时保持图形、自动保存、视口和撤销历史；手机仍可打开参数与配置。避免重新显示或计算技能树地图。
4. 输入框“参数”直接打开独立“模型参数”弹窗。沿用本站主题，参照提供图片使用温度滑块、当前数值、最大输出输入和高级停止词。保留模型默认温度、现有输出上限和版本冲突处理。保存成功后发送使用保存值，旧总配置移除生成参数分类。

## 实现边界

主要修改 TavernPage 的偏好和会话选择、ConversationPane 的顶部工具栏与画布布局、GenerationSettingsPanel 及独立参数弹窗。偏好读写和会话创建使用小模块隔离；画布延迟卸载或保留已有编辑器，避免收展清空撤销状态。

工具授权不因单纯展开画布或恢复模型偏好而改变；新会话沿用现有会话的授权状态。API Key 的校验和失败引导继续使用原模型接入配置。
