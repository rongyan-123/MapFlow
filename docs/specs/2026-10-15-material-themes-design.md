# MapFlow 温润纸感 / 石墨深色视觉设计

## 已确认的方向

用户选择「A 浅色 + B 深色，两套一起做」，确认全站视觉优化及手机、桌面验收。绿色退出界面品牌色。浅色对应铜棕和暖纸；深色对应淡紫和石墨。已展示的两张静态效果图是视觉参考，不代表已实现或可交互的产品。

本轮通过 skill-searcher 定位并安装 UI UX Pro Max，官方版本固定为 `nextlevelbuilder/ui-ux-pro-max-skill@56ea9cf174ed86786187daa9de0e6247cb0747e4`。实际检索设计系统、纸感和深色样式、对比度、焦点遮挡及现有 React 技术栈。宽泛查询返回的紫青 AI 配色及 Apple Liquid Glass 不符合本轮产品与用户偏好，未照搬；采用经核对的 `e-ink-paper`、`dark-mode-oled` 材质原则并以两张已确认提案为准。

前端基线 `7575cc440dedf45599858f30fcfc5fb7f9b90653`；复用现有隔离 worktree，使用 `codex/ui-material-themes-20261015`。固定主目录及所有 Codex 会话路径保留。

## 视觉语言

| 角色 | A 温润纸感 | B 石墨深色 |
| --- | --- | --- |
| 背景 | 暖纸 `#F7F2EB`，细腻层次 | 石墨 `#111319`，克制氛围光 |
| 面板 | 暖白 `#FFFDF9` | 炭灰 `#1D202A` |
| 文字 | 暖墨 `#302923` | 柔白 `#F2F0F7` |
| 品牌/操作 | 铜棕 `#9B4C32` | 淡紫 `#B9A5FF` |
| 分隔与阴影 | 暖灰细线、轻柔投影 | 清晰描边、层次阴影 |
| 装饰 | 水彩山径、折线路径标记 | 精细轨迹、低强度光点 |

所有界面颜色通过语义变量统一；用户地图、画布、角色原始图片等内容的自选颜色保持内容原意。常规正文目标对比度至少 4.5:1；可操作控件边界/焦点至少 3:1。键盘焦点始终可见。正文以清晰的中文系统无衬线字体为主，展示标题使用独立排印层级；不依赖境外字体服务加载。按钮、导航、卡片有完整的悬停、聚焦、按下、禁用、加载和错误状态。

材质来自表面色差、精细边框、低强度渐变、纹理和阴影；清晰内容面板保持不透明。动画主要为 140–240ms 的交互反馈，尊重 reduced-motion；不引入全屏粒子、动画背景或持续大面积模糊。

## 页面应用

- 全局导航与品牌：统一抽象路线标记，侧栏层次、选中态、账户区、顶部工具栏与手机抽屉；页面顶部单行结构保持。
- 全局助手：标题、欢迎插画、三张纵向问一问卡片与输入区域采用参考稿。保持唯一会话、原有问题池及只填草稿的行为。全局工具栏仍只有模型设置。旧消息、来源及执行状态沿用真实数据。
- 公共书库、我的地图、学习区：地图卡片增加装饰性路线封面与信息层次；真实标题、节点数、进度和操作仍来自现有数据。图形节点保持 240×104 的布局契约，按块排序和画布操作可用。
- 学习聊天与酒馆：角色列表、配置弹窗、画布工具栏、聊天气泡、模型选择采用统一表面与排印规范。平台助手角色隔离和所有会话操作保持既有语义。
- 产品首页与认证：视觉叙事、欢迎插画、标题、主要行动与登录表单形成连续品牌体验。
- 账户、模型、额度与管理后台：表单、价格、账务记录、表格、后台分区与知识库编辑采用同一组件语言，真实金额与权限状态完整显示。

## 主题兼容

外观菜单展示两套正式主题：温润纸感与石墨深色。既有 `light/dark` 键继续使用；旧设备的 `ivory` 映射到 `light`、`blue-gray` 映射到 `dark`。跨标签页同步、存储不可用回退、切换按钮及持久化均需先写测试再修改。CSS 保留旧 data 属性的渲染兼容，避免启动前短暂出现错误配色。

## 手机与验收约束

手机保持 52px 顶栏和至少 44px 触控区域。欢迎装饰不额外占据大块垂直空间；短视口和输入聚焦时减弱或收起装饰。聊天输入与软键盘共存，三张问题卡可完整滚动到输入框上方。普通页面保留现有手机导航；聊天模式沿用当前精简导航。

实际浏览器检查 320、390、768、1024、1440px，以及 390×500 短视口。每套主题检查助手、书库、地图、学习聊天、酒馆、账户/模型设置、额度、后台和关键弹窗。重点包括：长中文标题、无数据、真实数据、加载/错误、对比度、键盘焦点、无横向溢出、首屏空间和主题切换。完整 Vitest、typecheck 和 production build 通过后截图复核，再交用户验收。

视觉阶段交付可操作本机预览与实际截图。本轮用户确认的是设计和实现；生产发布另按用户后续指令执行。
