# 知识关系布局的主连线与局部展开

2026-10-30。用户确认默认减少连线，点击时只展开当前节点的全部直接关系；本轮只做本地验证。

## 显示规则

- 知识关系布局按目标节点选一条主连线：优先直接前置 `prerequisite`，没有直接前置时选一条指向该节点的知识关联。
- 同一优先级按知识关系布局中的节点距离选择最近的一条；距离相同或坐标缺失时按关系 ID 稳定选择，避免数据顺序改变导致跳线。
- 点击节点后，在主连线的基础上显示该节点的全部直接入线和出线。其他节点仍只显示主连线，不展开间接关系。
- 切换选择时收起上一节点的额外连线，取消选择时恢复默认显示。
- 按块排序沿用原行为：默认不画连线，选择后只显示当前节点的直接关系。

## 数据与交互边界

筛选只决定交给画布的连线集合，原始关系不删除、不保存筛选结果。布局计算、学习解锁、进度和详情继续读取完整关系。最近距离使用布局坐标，缩放、平移和临时拖动节点不会重新选择主连线。

保留现有节点位置、分支颜色、箭头、连线走向及流光规则。连线通道仍按完整关系分配，展开与收起不改变已有主连线的路径。拖动画布时隐藏、结束后恢复的行为继续保留。

用户此前同意的合并公共线段、重新绕障方案，由本次显示方案替换，本轮不实施。

后续用户另行确认只调整线条的就近绕行、分散端口与圆角，详见[连线走线设计](2026-10-30-map-line-routing-design.md)；节点排布继续保留。
