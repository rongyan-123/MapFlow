# 一次提交整张地图进度

用户已确认：全部点亮与撤销各一次请求、一次数据库事务，整张图同时渐变；失败整批不改，慢网可取消等待并核对实际结果。继续无二次确认，保留原百分比、原完成节点与后续手工修改。

## 范围与接口

复用原前端工作树并从最新 main 新建任务分支；后端在同任务的独立工作树完成。新增 `PUT /api/me/tree-library/{entry}/progress/batch`，接收 `operationId` 与 `changes: [{nodeId, expectedPercent, progressPercent}]`，返回操作状态和整张图的 `node_progress`。账号、Origin、CSRF、图与节点归属均由后端校验；单节点接口保持兼容。

同一事务锁定私人地图，整批验证目标和预期进度，再通过集合 SQL 写入并只推进一次学习状态版本。非法、越权、冲突或写失败不提交任何节点；相同目标重放不重复推进版本。无需数据库迁移或依赖变更，不涉及模型和账务。

前端先持久保存原进度日志，再发整批请求；收到成功结果后同时更新节点并沿用渐变。撤销也批量提交，仅恢复本次节点；其他窗口或手工调整过的进度保留。兼容旧版本本机撤销日志。

“取消等待”中断浏览器请求后调用 `POST /api/me/tree-library/{entry}/progress/batch/{operationId}/cancel`。取消与保存共享地图锁，使用现有通用变更回执表中独立的 `batch-progress.` 前缀记录；取消先到会阻止迟到的保存，保存先完成则明确返回 `applied`。原操作标识重放不会再次覆盖后来修改的进度，复用标识改变内容返回409。核对期间防重复提交，核对失败保留恢复记录及重试核对入口，不把浏览器取消等同数据库回滚。切换账号/地图时中止本视图请求，旧请求不得修改新视图。
