# 连线就近绕行与分散端口

2026-10-30。用户澄清本轮调整对象是线条，确认试用“附近短线、多条出线分散接出、就近绕障、小圆角”的方案。节点位置和此前确认的默认主连线、点击局部展开规则继续保留；只做本地验证。

## 路径

先尝试附近的短折线，受卡片遮挡时，在卡片间的空隙搜索路径。可以就近换通道，不要求一根竖直干线绕过全部障碍。搜索同时考虑距离与转弯次数。

同一节点的出线按目标位置分散接出。入线端口避开卡片左上方的学习状态标签。端口按完整关系分配，选择节点时不改变已有端口。共用通道的可见线段尽量保留间距，移动线段前核对相邻线段仍然避开卡片。

折线使用至多 6 个画布单位的小圆角。箭头、底线和流光共用同一路径，流光距离使用圆角后的实际长度。

## 缓存与边界

同一份节点几何共享障碍通道及路径缓存。仅选择、进度或视口变化时复用几何，避免在每次平移中重做路径搜索；节点位置或测量尺寸变化时更新几何。图形数据、布局、解锁规则和保存接口不改动。

固定节点和大量真实依赖仍可能产生少量相交或共用线段。拖动卡片产生重叠、使出口完全被挡住时，继续保留真实关系。缓存保留已绘制路径，展开其他关系时不让已有主连线跳动。

## 验证

短路径、分散端口、共用通道间距、小圆角及画布端口接入采用先失败再实现的回归检查。完整前端测试、类型检查与构建通过后，用独立后台 Firefox 和 Chrome 对同一 170 节点样本检查：节点不挪动、默认 162 条、选择全部直接关系、切换和取消、进度与颜色、拖动隐藏、按块模式及刷新。

对实际 SVG 路径取样检查是否穿过无关卡片，并核对 SVG 长度与流光距离。几何统计与本机计算时间用于本轮对照，不当作正式页面帧率或用户验收结果。
