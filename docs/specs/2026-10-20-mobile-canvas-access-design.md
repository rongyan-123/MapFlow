## 具体改法与验收

1. 手机学习区（宽度小于 1024px）首次进入收起画布，桌面继续沿用默认展开。绘图授权与展开状态分离，保留当前默认授权行为。用户主动切换后不因普通重绘、横竖屏变化或迟到读取而反复开关。
   - 可见状态以最后一次点击为准。加载中也提供可见的收起按钮；开关操作立即登记意图，不能等待读取结束才确定下一次点击是展开还是收起。
   - 展开和关闭在点击时立即更新可见状态；异步读取不再设置可见状态。文档读取和保存仍绑定原账号及会话的持久化实例，切地图、切会话或卸载后，原请求不能通过结束回调重新展开画布。已经返回或无法取消的结果也不改变最后一次点击的选择。
   - 默认绘图授权、历史刷新和 AI 绘图结果只更新原会话文档，不改变用户的展开选择。原会话的迟到结果不得修改新会话画布的显示或内容。
   - 先补手机进入、桌面默认、加载中连续点击、展开后立即收起再返回、开→关→开且读取乱序返回、读取失败后重试、切会话/卸载后旧请求返回的失败测试，再实现并跑绿。
2. 手机打开画布时占满聊天内容区；聊天和输入框暂时不可交互且不进入键盘焦点顺序，但不卸载，草稿、回复流和保存状态保留。顶栏保留始终可点的画布按钮，画布内保留“收起画布”。不新开弹窗，不再上下各分一半。手机画布工具栏压缩，关闭按钮不能被绘图工具挤走。
   - 移除针对手机画布的旧键盘规则：不再因 editing=true 将其压到 61px、切回聊天或隐藏绘图编辑器。保留 visualViewport 高度适配；画布内文字输入、画布快捷键设置和聊天输入分别验证，不能通过关闭全站键盘适配来解决。
   - 展开时让原聊天输入框失焦；画布文字编辑出现软键盘时，画布适应剩余可见高度，工具栏和收起按钮保持可达。键盘收起和横竖屏切换不改变开关状态、不丢文字、不重置绘图内容。
   - 画布内直接显示保存状态及错误：未保存、保存中、保存失败、已保存分别表述；只有实际写入成功且没有待保存改动时才显示已保存。保存失败提供“重试保存”，读取失败提供“重新读取”，禁止把保存重试接到重新发送聊天或模型调用上。
   - 保存失败时保留同一账号/会话的最新待保存元素和原版本依据；收起、重新打开及服务器旧版本回读均不能覆盖未保存内容。重新打开或读取成功不清除尚未成功写入的保存错误；收起后聊天侧继续提供未保存提醒，重新打开仍能看到失败和重试入口。
   - 重试沿用当前文档的保存队列，避免重复并行写入；以保存状态、版本和未保存内容是否清空判断成功，不能只因 onSave 返回成功结束就宣称已保存（当前 onSave 会在记录错误后吞掉异常）。只读、删除中或已删除时不允许发起保存。
   - 在 320/360/390/768、1024/1440px，米色与暗色实际截图；检查满幅、触控、关闭、草稿保留、无横向溢出。另测横屏、画布文字输入、软键盘弹出/收起、网络离线和保存失败后的恢复。
3. 工作台导航新增“Skill / MCP 接入”，桌面侧栏和手机导航抽屉均可直接打开已有教程，原“帮助与反馈”也保留入口；不与“模型与价格”混淆。
   - 用真实 Application 交互测试桌面与抽屉入口，核对“安装 Skill”“配置 MCP”章节可切换，关闭后仍在原页面。
   - 根据本地预览反馈，教程在小于 1024px 时取消顶部横向目录，左上角固定提供“目录”按钮，点击打开左侧抽屉。分组和全部章节垂直展示，目录可单独滚动；选中章节后自动收起并从正文顶部阅读，重新打开保留当前章节标记。桌面保留左侧常驻目录。
   - 目录的遮罩、关闭按钮和 Esc 只关闭抽屉，不能连同教程退出；关闭后焦点返回目录按钮。复用现有 Dialog 抽屉及主题，验证键盘焦点留在最上层、米色/暗色、320px 到桌面以及横屏，无横向溢出。
   - 根据后续预览反馈，正文结束处增加棕色实心“下一节：章节标题”按钮，沿现有目录顺序切换，正文回到顶部，目录当前项同步更新。米色和暗色均保留棕色与浅色文字，键盘焦点清楚可见；按钮跟随正文，不遮挡内容。最后一节显示“已读到最后一节”，仍可用目录切换。
4. 在公网 FRP 侧补 xxian.fun 的 HTTP 域名转发，目标为已有 Caddy 18090。优先使用独立 HTTP 转发进程和自动启动，避免重启承载 HTTPS/SSH 的现有进程；若服务商要求后台登记而拒绝新增路由，保留现场并报告具体原因，不绕过限制。
   - 先保存原配置和恢复方式，校验新配置，再验证公网首页、深路径和查询参数均 308 到相同 HTTPS 地址；HTTPS、SSH 与 readiness 持续正常。验证重启后的路由保留。
5. 从最新 main 开发时增加默认关闭的英语世界界面发布开关，避免此次普通前端发布重新展示已撤下功能。后端开关继续 false，原数据不动。
   - 开关关闭时无导航入口、深链接显示停用；显式本地启用测试仍可运行。核对默认构建产物。

## 修改范围及收尾

前端聊天状态、画布展开意图与保存错误状态、画布内保存反馈、共享聊天布局/样式、工作台导航及 Application、相关回归测试与验收文档。HTTP 仅涉及专属转发配置/自动启动和运维说明，不改收费、模型、数据库、收款监听或 Codex 会话。未保存内容保留以当前账号的浏览器会话和已有 QueryClient 缓存生命周期为范围，不把本次修改描述为新增刷新后或退出登录后的离线存储。

## 三项审阅意见对应的必过检查

| 检查 | 方法 | 通过条件 |
| --- | --- | --- |
| 全屏画布保存失败可见 | 组件/页面交互测试，让保存返回网络失败与服务端失败；手机截图复核 | 画布内可见失败与“重试保存”，不能只显示“自动保存”；聊天隐藏时仍可处理 |
| 收起后重开保留失败和内容 | 使用实际持久化层保存失败，再收起、重开并返回旧服务器数据 | 未保存元素和失败状态保留；重试成功后才清除，已保存版本与最新元素一致 |
| 保存中继续编辑与重复重试 | 暂停首次写入、继续改图并连续点击重试，再依次完成写入 | 写入按队列串行，最终保存最新内容；旧保存结果不覆盖新草稿 |
| 只读与删除保护 | 失败草稿进入只读或删除准备状态，再操作重试入口 | 不额外写入、不丢草稿，沿用已有删除前 flush 保护 |
| 键盘不隐藏画布 | 浏览器聚焦实际绘图文字输入并改变 visualViewport，分别测竖屏与横屏 | 编辑器始终显示且大于旧 61px 工具条高度，收起按钮可达，内容与开关状态不变 |
| 键盘兼容性 | 真实安卓浏览器验收；若只能模拟，则明确记录限制 | 实际输入、弹出/收起和横屏有记录，不把桌面模拟说成真机通过 |
| 加载中最后点击生效 | 实际 Hook/页面测试中控制网络 promise 完成顺序 | 开→关保持关；开→关→开保持开；乱序返回不改变最后意图 |
| 会话隔离与卸载 | A 会话加载时切到 B、切账号或卸载，再返回 A 的旧请求 | 不打开 B、不改变 B 的文档，不发生失效的可见状态更新；A 的保存仍归属 A |

本表是实施时的验收要求；方案制定阶段仅完成源码核对和两项内存时序复现。实施后的实际结果单独登记在[本地验收记录](../research/2026-10-20-mobile-canvas-access-local-acceptance.md)，不把制定方案时的复现当作完整回归结果。
