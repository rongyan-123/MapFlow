# 学习画布默认行为与主题收拢切换

按本轮用户明确要求实施，延续已完成的酒馆独立智能体界面。前端基线为 `main f018a4f` 加已提交的酒馆改进 `e22e357`；后端基线为 `main 4dba638`。复用现有隔离工作区，分别使用 `codex/learning-canvas-theme-transition-20261016`、`codex/learning-canvas-defaults-20261016`，固定主目录保持 main。

## 学习与酒馆

- 每次进入可用学习会话，自动加载并展开该会话画布，默认开启“允许 AI 绘图”。本次访问内允许主动收起或取消绘图；普通消息/保存更新不重新弹出、也不反复勾选。再次进入恢复学习默认。只读历史不产生保存请求，清空后的空状态不自动创建聊天。
- 新学习会话在原创建事务中初始化允许绘图的空画布；已有学习会话由进入流程通过原有带版本接口确认授权，保存失败明确展示，避免仅在界面假勾选。权限、修订号和生成冲突保护沿用现有接口。
- 酒馆默认收起画布，包括以前授权 AI 绘图的会话；入口继续保留，用户可以手动展开和授权。不会因画布有内容或曾开启绘图而自动弹出。
- 默认教学角色说明加入图示教学建议；学习场景本轮执行提示同样加入，覆盖已有学习会话而不改写旧角色卡或聊天。建议把结构、流程、空间关系、推导与例题放到画布，先 `read_canvas` 再 `apply_canvas_patch`，保留用户笔迹；只有运行时确实提供画布 skill 才使用该 skill，工具未授权时不得假装绘制。
- 桌面同时展示画布和对话。窄屏调整画布布局，确保默认画布不会把聊天输入整个隐藏；保留收起、地图切换与键盘输入能力。

## 主题动效

- 米色与暗色切换时，新主题先在底层准备，旧主题完整画面在上层，以触发按钮/选择控件中心为圆心，从覆盖视口的半径收缩至零，约 600ms；两种方向使用相同收拢逻辑。
- 使用浏览器 View Transition 快照和裁剪动画，不复制页面 DOM，不重建画布/聊天、不改变滚动位置。桌面侧栏按钮、手机导航抽屉按钮和设置页主题选择都提供自己的坐标。
- 连续切换取消上一动画，最终主题和本地偏好保持一致；初始化、跨标签页同步不播放整屏动画。系统“减少动态效果”直接切换；不支持快照 API 的浏览器使用短颜色过渡。

## 实施与验收

1. 在用户交互与 HTTP 边界先写学习区默认展开/授权、手动收起与取消、重进、只读历史、酒馆默认收起的失败回归，再实现；后端以公开会话接口和冻结执行提示验证默认画布与教学建议。
2. 主题控件先验证点击源坐标、状态同步、连续切换、API 失败和减少动态效果，再实现圆形收拢及兼容过渡。
3. 本地真实 API 检查学习/酒馆及提示契约；320/390/768/1024/1440px、两套主题、手机键盘和长名称检查，截图并检查主题动画中间帧。不调用付费模型、不访问生产写接口。
4. 完整测试、TypeScript/Rust 检查、生产构建、diff 自审和固定入口检查；提交结果与验收记录。本轮不部署。
