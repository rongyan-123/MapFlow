# 技能树卡片悬停操作抽屉设计

## 背景

个人树库中的 `TreeChoice` 当前把导出按钮放在卡片右下角，并通过明显的左边框与内容区分隔。窄侧栏下，标题区域容易被压缩，操作区也显得像一个外挂按钮。

## 目标

- 让个人技能树卡片具有更清晰的层次、阴影和悬停反馈。
- 将操作入口整合到卡片右侧的纵向抽屉中，去掉突兀的硬分隔线。
- 保留导出功能，并为后续重命名、删除功能预留一致的操作入口。
- 桌面端使用悬停/键盘聚焦展开；没有 hover 能力的移动端保持操作区可发现且可点击。
- 不改变技能树数据、导出内容、接口或后端行为。

## 交互设计

### 桌面端

卡片默认显示标题、学习进度和选中状态。鼠标移入卡片或键盘焦点进入卡片操作区时：

1. 卡片轻微上浮，边框和阴影增强。
2. 左侧内容平滑收紧。
3. 右侧操作抽屉从零宽度向左展开，依次显示：
   - 青色：导出（当前可用，打开 JSON/Markdown 导出窗口）；
   - 琥珀色：重命名（预留，当前禁用）；
   - 红色：删除（预留，当前禁用）。
4. 鼠标移出且没有键盘焦点时，抽屉收回。

操作按钮不触发卡片选中事件。预留按钮明确显示为禁用状态，并提供“即将支持”的辅助提示，避免造成可用功能的误解。

### 移动端

移动设备通常没有 hover，因此操作抽屉默认展开为紧凑的纵向操作区；每个操作保持至少 44px 的触摸高度。标题区使用剩余空间，不覆盖标题或学习进度。

## 视觉设计

- 卡片使用主题感知的渐变背景、内侧高光、柔和外阴影和圆角。
- 选中卡片使用青色边缘光，普通卡片使用低对比度边框。
- 抽屉使用半透明背景和内侧柔光作为软分界，不再绘制当前的硬 `border-left` 线。
- 动画时长约 220–300ms；在 `prefers-reduced-motion` 下关闭位移与宽度动画。
- 浅色与米色主题使用独立的浅色阴影和文字对比度，不能复用深色渐变导致文字不可读。

## 实现范围

- 更新 `TreeChoice` 的卡片布局和操作抽屉样式。
- 为导出按钮增加抽屉样式变体，保持现有导出弹窗与懒加载逻辑。
- 添加重命名、删除的禁用预留按钮，不新增后端接口。
- 在现有前端测试中覆盖抽屉动作归属、导出行为、预留按钮禁用状态和桌面头部不重复出现操作。

## 验收标准

- 桌面端悬停或键盘聚焦卡片时，右侧抽屉平滑展开，卡片内容不会溢出或被遮挡。
- 导出按钮在抽屉中仍能打开现有导出格式选择窗口。
- 重命名和删除按钮颜色不同且明确不可用，不会发起请求。
- 移动端无需 hover 也能看到并点击导出入口，所有操作触摸区域不小于 44px。
- 深色、浅色、米色主题下文字和按钮均保持可读。
- `npm test`、`npm run typecheck`、`npm run build` 全部通过，并用 Browser Harness 实际检查桌面和窄屏 DOM 交互。
