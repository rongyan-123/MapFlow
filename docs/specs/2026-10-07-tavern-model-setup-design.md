# 酒馆模型接入引导与价格

用户已确认范围：报错直接打开模型接入；服务预设、连接测试和保存；平台模型显示本站价格。按当前 main 开发，验证后合并 main 并发布到笔记本。

## 交互与接口

- 未填 Key、模型、错误接入配置或模型连接失败时显示“填写 API Key 或使用平台额度”，点击直接打开模型接入页签，保留原消息与重试身份。额度不足提供充值入口。
- 预设：爱你 AI、DeepSeek、OpenAI、通义千问兼容接口、自定义。预设切换清空 Key 和连接结果，允许手填模型 ID。
- 配置使用草稿，点击“保存并使用”后才改变发送配置。保存校验必填字段和地址；切换平台模式保留本页面已保存的自填配置。Key 仅在当前页面内存，不写浏览器存储或数据库。
- POST /api/me/tavern/model-access/test，复用酒馆登录、CSRF、限流与公网 HTTPS /v1 地址校验。请求包含 apiKey 和 baseUrl；仅 GET 上游 /models，返回有界模型 ID 列表。禁止重定向、内网地址和代理，固定已验证 DNS 地址，限制超时及响应体。上游错误正文不回显，Key 不入日志或响应。模型列表不等于保证每个模型可生成，界面明确测试范围。
- 平台选择复用 /api/model-catalog/pricing 的已计算本站 CNY 价格，显示可用渠道输入和输出的最小至最大值（每百万 Token），价格缺失明确显示暂无报价。不再乘倍率，价格变化以实际账单为准；不显示上游折扣或利润公式。

## 验证步骤

1. 用户点击错误引导直接到模型页签，消息不丢失：酒馆集成测试先红后绿。
2. 草稿、保存、预设切换清 Key、不同线路配置保留、连接结果失效及晚到响应隔离：配置组件行为测试先红后绿。
3. 测试接口认证/CSRF、公网校验、上游成功/拒绝/异常/有界响应及不扣费：HTTP 边界测试先红后绿，使用本地测试上游验证传输，不依赖真实付费 Key。
4. 平台价格区间、缺失价格和未二次乘价：前端组件测试。
5. 前端完整测试、类型检查、构建；后端完整测试、fmt、Clippy；自审 diff。合并 main 后基于 main 构建，克隆数据库验证、新旧配置比较、公网检查，保留仅回滚应用的镜像，不回滚收款数据库。
