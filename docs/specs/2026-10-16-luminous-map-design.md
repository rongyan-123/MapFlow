# 亮色地图与学习反馈恢复

## 已确认范围

用户确认恢复地图的节点状态、定向流光、分组氛围、完成反馈与进度总览，并要求以亮色环境实现，避免黑色地图背景。沿用全站已确认的温润纸感 / 石墨深色主题；地图按浅色主视觉设计，不为特效强制切换主题。当前主题工作已保存为 f9fb8c7，在同一独立工作区和 codex 分支上继续完善，固定 main 入口及会话目录保留。

## 视觉方案

地图采用暖白画布、细点阵、低饱和蓝紫氛围与白色节点。强调来自有颜色的清晰线条、节点边缘和局部阴影。前置关系用墨蓝，后续关系用紫色，两者均有箭头、文字图例和流动高光，不靠颜色独立表达语义。

未开始节点保持安静；学习中以琥珀边缘和低强度呼吸提示；完成使用珠光紫色表面与勾选，掌握保留独立金色与星标。保留现有真实状态含义，不新增掌握写入或伪造当前节点。节点尺寸仍为 240 × 104，不改变连线路由和布局几何。分组使用原分组颜色的淡色泳道、细线与局部柔光。

完成反馈保留“此间事了”，在地图区域内呈现暖白、金色扫光与节点标题，约 2.6 秒后消失，可立即收起。地图始终保持亮色与可读文字。减少动态效果偏好下禁用扫光、呼吸和流动，只显示静态成功反馈；不为全图每个节点叠加无限高成本滤镜。

现有深色主题继续可用，通过地图语义变量调亮状态边缘和分组区域，不把浅色方案改成黑底展示。两主题分别检验文字、控件和线条对比度。

## 交互和数据契约

- 桌面详情改为不遮住画布的侧栏；手机改为可收起的底部详情，无模糊遮罩、不锁住整张地图。提供收起、重新打开和取消选择操作。收起详情保留节点与关系，取消选择才清除关系。
- 选择其他节点展开其详情；切换地图、账号或入口时清理旧选择、笔记与完成反馈；保留深链接的布局和节点定位。笔记仍使用原独立编辑弹窗。
- 进度总览按当前地图节点与真实进度计算平均完成百分比，统计已完成、进行中与未开始；空图为 0。公共预览不显示个人进度。
- 完成动画只在本页用户主动标记完成或将详细进度保存到 100%，且服务器确认成功后触发。初始化、查询刷新、保存失败、取消完成不触发。保存未结束时拒绝重复提交；旧地图请求迟到不影响新地图。
- 使用现有进度接口；页面把 mutateAsync 的确认结果交给地图处理反馈，错误仍由既有 mutation 错误区显示。不增加后台接口、依赖或独立状态源。

## 步骤与验证

1. 修复详情与选择行为。以现有 MapView 用户界面为测试边界，先跑红再实现：无模态遮挡、收起后关系保留、重开、取消、切图重置、深链接可用。
2. 恢复真实进度总览。以地图呈现为边界，先测试已知进度的结果与公共预览，再实现。对齐总览、节点和小地图状态。
3. 恢复完成反馈。以用户保存及服务器 Promise 回执为边界，先测延迟成功、失败、重复提交、详细进度 100%、切图和卸载迟到回执，再实现。
4. 应用独立地图视觉样式与局部动画。纯 CSS / SVG 调整不写样式镜像测试，实际检查相同数据的节点状态、选中、关系、分组、拖拽和缩放。
5. 完整 Vitest、typecheck、production build；自审 diff。使用隔离 API 验证真实地图和进度保存，检查 320、390、768、1024、1440px、手机短视口和 reduced-motion，截图后交用户验收。
