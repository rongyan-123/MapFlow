# MapFlow 流式聊天、界面与教学画布：调研及实施草案

日期：2026-10-07。状态：用户已确认三项范围，优先搭建教学界面和可用绘图工具，再补齐流式过程。

## 目标与已确认事实

用户要求改善长时间等待和分散的聊天头部，参考所附聊天产品的消息与输入区布局，并调研能让 Agent 用代码作图的无限画布，服务于技能树教学。

当前前端 main 为 270ac29，后端 main 为 87673db。前端 React 18 + TypeScript，后端 Rust + Axum + PostgreSQL。

当前正文已有完整 SSE 路径：ConversationPane → tavernClient.generateStream → http/tavern → tavern/service → adapters/model/openai_compatible。上游请求 stream=true，正文 delta 按事件转发。上游返回的 reasoning_content 未纳入酒馆解析；前端只处理 delta/completed/error/approval_required，未展示 started 和工具执行进度。因此应在现有链路补齐可见过程，并实测首段时间，而不是再做一套聊天接口。截图中的等待原因尚需用控制上游分段事件与正式链路时序区分，不能只凭截图认定为代理缓冲。

现有 UI 分为 App 的节点条、TavernPage 的角色工具栏与关联说明，宽屏中多个按钮使用 justify-between 分散排列。ConversationPane 的用户与助手同用带头像的居中块，输入区只有发送和换行提示。已有模型选择、平台额度/BYOK、温度、最大输出 Token、停止词和部分模型的思考参数，可以在输入区提供直接入口。

## 建议的实施顺序

### 1. 流式过程

在现有 SSE 上增加类型化的思考/摘要事件和工具状态事件，保持正文、完成回执和幂等请求兼容。公开返回的思考/摘要用可折叠区域展示；没有该字段的模型展示生成和工具状态。成功轮次的公开思考/摘要及工具过程按 generationId 随会话保存，刷新和两处酒馆切换后可查看；失败时的未完成内容保持中断状态，不当作成功回复保存。按帧节流 Markdown 渲染，滚动跟随只在用户处于底部时生效。提供停止生成及断流后的明确状态；停止时若本轮已经成功提交，则恢复保存的回执。

模型支持的思考参数由现有模型元数据决定；不向所有模型统一强塞参数。平台和自填 Key 两条路径都验收。收费继续依据服务端完整成功账单，显示思考不重复计算用量；余额大于 0 可发送、允许成功结算跨零、失败不扣本站现金、重试不重扣。

验证：先写控制上游延迟帧的红测试，证明正文和思考在 completed 前已可见；覆盖工具多轮、UTF-8 拆包、长 Markdown、取消、断流和重试。用直连后端、中间代理、公网浏览器逐层测首事件时间。

### 2. 共享聊天 UI

将截图圈出的节点、返回、角色列表、角色信息、关联树和配置入口整合成紧凑工具栏，保留地图入口。消息区助手正文左对齐，用户消息右侧气泡；压缩重复头像、身份标签和操作按钮。输入区统一放置模型、平台额度/BYOK、上下文档位、生成参数、工具入口和停止/发送按钮。参数入口复用既有设置与保存功能，实际费用仍以完成回执展示。

参考截图中的中性色背景、圆角输入面板、清晰字体层级及角色快捷入口，并同时支持现有明暗主题。学习酒馆与独立酒馆共用组件、角色和会话。只有已接入且可用的能力呈现为可操作入口。

验证：桌面与手机浏览器检查头部高度、按钮排列、长文本、代码块、空会话、生成中与报错状态；回归角色切换、配置保存、历史互通和收费入口。学习聊天继续卸载技能树地图。

### 3. 最小教学画布

在同一会话内懒加载 Excalidraw 教学画布。开启后桌面为左画布、右聊天，可收起并通过预设宽度调整；手机切换聊天/画布标签。宽度变化只影响白板与聊天容器，不重新挂载或重新布局技能树。

第一版提供文字、矩形、圆形和箭头、读取当前画布、添加/更新图形、用户编辑与撤销、刷新恢复。Agent 通过受约束的 read_canvas/apply_canvas_patch 工具逐步作图，输入为结构化数据，不运行任意 JS。画布绑定账号和 conversationId，两处酒馆共享；教学画布与技能树工具分别授权；用户点击“绘图讲解”时开启画布和 AI 绘图授权，可随时关闭该授权，技能树工具开关继续单独控制。

AI 改动先预览，成功的会话、账单和画布版本一起提交；失败撤销本轮 AI 预览，保留此前画布。手工编辑与 AI 绘图通过版本约束避免互相覆盖。第一版不包含多人实时协作或图像生成。

验证：先用工具请求红测试覆盖读取、绘图、版本冲突、权限和重复请求，再跑真实 Agent 画一张“浏览器 → API → 数据库”教学图。检查撤销、刷新和两处酒馆互通；测试连续输出时画布拖动与收起的响应，确认未调用图像生成接口。
