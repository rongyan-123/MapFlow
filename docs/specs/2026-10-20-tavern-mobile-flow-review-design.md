# 酒馆手机入口、角色库切换与新建反馈

日期：2026-10-20。按用户对本地预览的三项具体反馈继续修改现有开发分支；不合入 main、不部署，完成后仍交由用户查看本地界面。

## 界面和行为

1. 酒馆窄屏顶栏将会话按钮和角色下拉合成一个显示当前智能体的按钮，点击打开现有会话抽屉。完整角色库选择、该角色的历史和新建放在同一抽屉；选角色或选历史后返回聊天。学习区顶栏保持本轮之外的既有行为。
2. 角色库保留一个弹窗，上方固定提供“我的角色 / 导入角色卡 / 创建角色卡”。导入、创建切换内容，不再替换成另一弹窗，切换不丢未提交的名称、设定、开场白或导入预览。保存过程中禁止切换和关闭；失败保留表单并显示错误。成功回到角色列表，新增角色立即进入选择列表，不自动替换当前聊天。编辑和删除沿用已有确认流程。
3. 新建会话成功后收起手机抽屉，显示并选中新会话；创建中防止重复点击，失败保留抽屉及原会话并显示错误。历史按创建时间倒序排列，最新置顶，每条显示编号、创建时间和当前标记；同时间保留接口已有顺序，搜索不改变编号。编号是当前列表按创建顺序显示的序号，不新增数据库标识或承诺删除后仍保留原编号。
   - 浏览器实测复现旧列表同步 effect 再次选中原记录的问题；同步只修复缓存中确实不存在的选择，初始化角色偏好不再触发重新选中，防止新建或切换被旧渲染覆盖。

保留独立智能体、学习区与全局助手的会话隔离、原创建去重与失败恢复、草稿及画布保存保护，不修改计费、后端接口或已有历史数据。以复用角色库弹窗和表单实现；继续叠加弹窗会保留用户指出的往返问题，故不采用。
