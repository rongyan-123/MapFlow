## 范围与限制

- 航班是打包的上游数据驱动的视觉动画，不是实时航班服务；手机按 900 航班预算，桌面按 2,800 航班预算。
- 尺寸与手势在本机 Chromium 的移动模拟中验收，不等同于多款实体手机性能保证。RAF 间隔不是 GPU 渲染耗时。
- 本轮末次桌面观察中数据解析约 23.8ms，解析至安装 renderer 约 100.1ms；初次揭示仍有短暂同步构建成本。开场隐藏时延后航班加载。
- Vite 仍提示主 JavaScript chunk 超过 500kB。未在本轮扩大到应用级拆包。
- 可见的多余来源页脚已移除；完整来源与许可证保留在第三方声明、模块 LICENSE 和参考来源文档。
