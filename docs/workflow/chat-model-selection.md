# 聊天模型选择

全局助手、学习聊天和独立酒馆共用 `AgentModelProvider` 与 `ModelSettings`。现金模型全部来自 `/api/me/agent-models` 的 `cash` 数组；`defaultCash` 仅用于首次默认选择，不是可用模型过滤条件。

用户显式选择的模型若从目录消失，保留其选择意图并要求重新选择，不偷偷改用默认模型。服务端拒绝旧版本时，保留输入、清除已经明确未受理的重试身份、刷新目录；下一次由用户发送新请求。BYOK、积分及已接受执行的恢复保持独立。

管理后台“模型”页提供独立目录操作：同步来源、单项或批量验证、开放/暂停选择、设为默认、读取/取消原批次，以及只检查原始依据的核对按钮。普通打开页面仅 GET；同步只获取元信息，付费验证必须点击按钮。

新管理目录使用独立接口，避免给严格解析的旧用户目录追加字段。旧服务端没有新接口时提示升级，不自动调用旧启用接口。

2026-10-17 验收：前端 684 项通过、1 项跳过；类型检查和构建通过。使用真实 API 验证后的 47 个模型作为浏览器目录，三个聊天场景在 320、390、1024、1440px 可选择 Claude 等非 DeepSeek 模型；管理页检查 320、390、1440px，共 15 张截图，无页面异常和横向溢出。页面请求全部由隔离数据响应，没有向真实会话发消息。

后台持久化、收费验证、并发和回滚要求见后端 `docs/operations/chat-model-catalog.md`。真实测试的密钥和原始调用归档留在本机私有目录，不随前端构建发布。
